# Core Canon Decisions

**READ ONLY** — Цей документ містить відповіді на ключові питання світу.

## Locked Spellings

- Laurasia(Лавразія) — the main continent where events take place
- Gondwana(Гондвана) — the second continent, referred to as the "Distant Land"
- Omniport(Омніпорт) — the main port city
- Malek(Малек) — один з персонажів, грає Міша
- Donnie(Донні) — один з персонажів, грає Софія А.
- San Shu(Сань Шу) — один з персонажів, грає Алона.
- Minerva(Мінерва) — одна з персонажів, грає Софія Р.
- Hanna(Ханна) — відкрита науковиця, відкрила сита ману
- Amadeus(Амадей) — незалежний маг-дослідник, помер 1 рік тому
- Nika(Ніка) — богиня перемоги (поконюється Мінервою)
- Terikon(Терикон) — колишнє місто, тепер район Омніпорта
- Knokenbach(Кнокенбах) — шахтарське містечко на березі моря
- Lab-S3.2 — лабораторія фундаментальних досліджень (на межі, чорний блиск)
- Lab-M4.3 — мінне підприємство, запечатані дварфи

## Хронологія (CANON)

| Рік | Подія                                                            |
| --- | ---------------------------------------------------------------- |
| -15 | Перша використання темної мани (15 років до кінця війни)         |
| 0   | Кінець війни (60-річна війна завершилася)                        |
| +6  | Сьогоднішній день. Пройшло 21 рік від першого використання мани. |

## Суті

- **Темна мана** = **Чорна мана** = **Black Mana** (усі назви є синонімами)
- **Сита мана** — підвид Чорної мани, відкритий Ханою
- **Пайок (RU)** — добова норма здорової людини: 1 фунт сухої їжі + 1 галон чистої води
- **Гондвана** — континент, куди втекла еліта знання
